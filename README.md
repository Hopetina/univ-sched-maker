# UniExam Scheduler

Create an ASP.NET MVC 5 application using C#, Entity Framework and SQL Server for a University Examination Scheduling System.

Implement:

- ASP.NET Identity authentication

- Role-based authorization

Roles:

- System Admin

- Department Admin

- Lecturer

Database entities:

- Faculty

- Department

- Student

- Lecturer

- Module

- StudentModule

- Venue

- ExamPeriod

- Timeslot

- Exam

- AuditLog

Requirements:

- Generate Entity Framework models

- Create CRUD pages for all entities

- Use Repository and Service patterns

- Use SQL Server as the database

- Generate clean layered architecture

Do not implement scheduling logic yet.
